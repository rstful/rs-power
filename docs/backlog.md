# rs-power 백로그

지금은 만들지 않지만 앞으로 추가할 후보. 컨텍스트 가드·단계별 모델 지정 MVP 의 범위에서 뺀 것들이다.

| 항목 | 내용 | 지금 빼는 이유 | 다시 볼 시점 |
|---|---|---|---|
| 비용($) 환산·대시보드 | 토큰 사용량을 달러로 바꿔 세션·기간별로 보여 준다 | MVP 는 경고·차단만으로 소진을 줄이는지 먼저 검증한다 | 배포 1개월 측정 뒤 원인 분석이 필요할 때 |
| 팀 사용량 집계·리포트 | 계정·개발자별 사용량을 모아 보고한다 | 수집·저장 경로와 개인정보 처리 설계가 먼저 필요하다 | 소진 계정 수 목표(3개 이하)를 못 맞췄을 때 |
| 개인별 임계값 설정 | 400k/600k 를 개발자나 저장소마다 바꾼다 | 고정값으로 팀 기준을 먼저 세운다 | 고정값 때문에 훅을 끄는 사례가 나올 때 |
| 단계 자동 감지 | 대화 내용을 분석해 현재 단계를 판별하고 모델을 바꾼다 | MVP 는 스킬 호출 기준으로만 단계를 나눈다 | 스킬을 거치지 않는 작업 비중이 클 때 |
